How do I connect an API?

Run the Vynqode Node server locally, set the matching provider key in its environment, restart it, and open http://127.0.0.1:3000. For example, set OPENAI_API_KEY for OpenAI, ANTHROPIC_API_KEY for Claude, or GEMINI_API_KEY for Gemini. GitHub Pages alone cannot securely run paid APIs.
